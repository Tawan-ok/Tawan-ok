## 🧑‍💻 About me

- 🚀 In the AI era one person can build it all: **backend, frontend, bots and automation**
- 🔭 Building **[LidServer for Windows](https://github.com/Tawan-ok/lidserver-windows)**: turn a laptop into a 24/7 server with the lid closed
